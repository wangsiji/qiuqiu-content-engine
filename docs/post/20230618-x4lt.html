大家好，我是秋秋！

终于！！！要给大家出「新疆旅行攻略」了。

在新疆，我看到了湖泊、草原：

雪山、沙漠：

也感受了不同的人文和少数民族朋友的热情。

当然，吃了不少好吃的😋

新疆真的太大太大，今天只先写「吐鲁番：3天2夜580」攻略。

去新疆，可以安排！

一、吐鲁番，我来了！

吐鲁番，作为北疆“火洲”，最有名的就是葡萄。

旅游旺季是每年5月～6月初，8月9月水果成熟时！

你可以看到遍地瓜果飘香，也能感受到物价的友好。

去吐鲁番很方便，可以选择火车和飞机。

火车距市区10公里左右，打车30块钱。

飞机大概15公里，打车也不到40块钱。

吐鲁番市区的景点都不远，打车完全搞定！‍

周边辐射景点多，大家打车的时候可以留下师傅电话，包车4个人一天300-400左右，供参考。

二、吐鲁番景点路线

新疆和内地有2小时时差，吐鲁番是盆地夏天更热，建议18点之后再出门。

别担心时间不够！玩到晚上11点，刚日落结束。

吐鲁番景点可以分为市区和周边，建议安排2天。

第一天：市区

比较推荐葡萄沟、郡王府、博物馆。

🌟🌟🌟🌟🌟葡萄沟：

国家5A级景区。是把一个大村落给围起来，很有氛围感。

在这里，每家每户都种植葡萄。

有个巷子，家家户户的门都很好看。

关键！还很凉快！

你像走进了葡萄小镇，也像回到了童年。

西瓜一块钱一斤，能碰到很多上学的小孩......

葡萄沟里面也有民宿，大家定的时候可以选择～

🌟🌟🌟老爷爷的古董店：

是在网上看别人拍的照片好看就过去了。

注意！这个周围没其他景点。

对地标打卡感兴趣的，打车10元内可以去看看。

🌟🌟🌟🌟🌟郡王府：

超级推荐的一个景区！是王爷的家，非常豪华。

前面是两层小楼，后面是住的地方，还有地道、坎儿井、葡萄架～

每一个地方拍照都很好看，关键人也不多～

🌟🌟🌟博物馆：

免费的，搜索「吐鲁番博物馆」预约就可以进。

最有名的就是干尸展览馆，我去的时候没开放，比较遗憾。

值得一提！周边有个烤包子是百年老店，一定吃下。

第二天：周边

吐鲁番周边一日游淘宝、去哪儿都有团。

一般包括：火焰山、坎儿井、千佛洞、交和古城 、麻扎村、库木塔格沙漠。

我是青旅组织拼车，4人AA，120人/天，5座车，吃饭AA。

火焰山不用买门票进去！一路上都能看到。

记得去后门，有一些雕塑很好看，还不要钱。

坎儿井郡王府就有一小段，夏天可以安排，比较凉快。

交和古城建筑很有当地特色。

麻扎村是本地人的一个村子，是个古老村落，建议慢慢在里面逛：

沙漠，是最远的。

但是看一场沙漠日落真的很浪漫！

三：吐鲁番美食

吐鲁番物价！是我在新疆去了好几个城市里，最便宜的！！！

羊肉3块钱一串：

很大嘎嘎香～

烤包子2元、拉面8元送个鸡蛋。

市区美食推荐：幸福街。

整条道都是好吃的。

缸子肉、架子肉、拉条子，各种美食你就直接铉～

不用刻意去找，看到本地人多就是最好的口碑。

四：吐鲁番花费

最后，直接放一下我的账单，共计：572。

住：民宿51×2，102

吃：4人AA，25×6，150

玩：包车AA120，郡王府门票30，沙漠门票30，葡萄沟租电动车40

其他：干果101，包邮到北京。

住我还是选择的青旅，6人间上下铺带空调和独卫，公共区域这个样子，挺满意的：

吃：熟悉我的小伙伴知道我是一天吃2顿。

这边物价低，平均25块钱就搞定。

玩：市区近的就走路过去，有一天还说包车，开销都不大。

大的开销，是买了干果100多。

反正一共580，搞定。

✨

我对吐鲁番的评价，是非常值得去！

很美好的一个小城市，可爱在青旅院子里慢悠悠，和小伙伴抱着西瓜聊天。

还会在葡萄沟里，遇到热情好客的老奶奶。

3块钱超好吃超大的羊肉串！（到了喀什一串5块、阿克苏一串8块）

很适合慢慢逛～

希望这篇吐鲁番旅行攻略能够帮助到你。
