大家好，我是秋秋呀。

忙碌的7月终于结束了。这一个月我开始尝试用子弹笔记记录生活，日历也安排的满满当当。

中间有一段时间因为笔记本弄丢了，导致一周过的一团糟。我才发现原来APP、日程本对我有多重要！

所以今天就来总结下，我现在的时间管理方式，以及特别好用的小工具吧～

NO.1

日程本

我还是非常建议大家买个小本子来做基础的时间管理的。第一是随时带出门很方便，第二记录的仪式感会加深印象。

现在主要用的是这2款，左边国誉自我手帐和右面hoboweeks。

//hoboweeks

这个本子内页前面是日历，中间是周计划，后面是空白页自由发挥。

我现在的用法是把后面的空白页做子弹笔记（[子弹笔记教程](http://mp.weixin.qq.com/s?__biz=MzI4NzU3ODk5NQ==&mid=2247486394&idx=1&sn=8813e17253bbd1f1cd21b94994234960&chksm=ebcac5a6dcbd4cb0ffec1f54af1261d9deeb77fffc01cde58dfe7f3a3700aae1796bca293670&scene=21#wechat_redirect)）

前面的日历用来做我抖音和公众号排期，你也可以写下你每月的大事件。比如要交的作业，朋友生日，出行计划之类。

这一个月的大事都在这里，一打开就会特别心安。

中间周计划以前我是写每天要做的事，现在我是用来写成功日记。

每天记录下自己最开心的几件小事，这个习惯真的非常有用，慢慢的会了解自己的心情习惯，以及正反馈很多越来越自信。

// 国誉自我手帐

这个本子的内页是时间轴的样子，从早晨到晚上每天做了什么都能一目了然。

所以我的用法是回溯，一天结束之后，再去写下每天做了什么，以此来观察自己的时间。

如果是做计划不建议用这种本子，因为把每个时间段都安排没有灵活性，没照着进行打击会比较大。

另外，我还发现来一个非常好用的方法，色块检查法。

就是把每周的规划分别写在左面或者右下角，比如红色学习、蓝色工作、黄色学习。

然后再把时间轴按照发生写满，这样等一周过去，每一个色块的时间大致一看，这周时间花哪里了一目了然。

以上，hoboweeks来做我的月工作规划和每日心情，国誉自我做时间反思（不好好工作学习的时候一看时间轴会特别愧疚）。

NO.2

日历

除了我的公众号抖音排期，我还会把每天的生活安排下来。

大概就是做个日常时间表，标记出像喝水、健身、喂狗、学习这种事情。因为如果不给我一个明确的指示，我很容易忘记。

这里我用的最好的时间管理app就是手机自带日历。它的好处是颜色简洁小清新、可以随便添加删减事情，还能手机自动提醒。

举个例子，每天晚上8——10点是我的学习时间，但我经常一看剧就没完没了，提前用手机日历做好每天的安排，这样到点手机就会有提醒，非常方便。

生活中有一些不太重要的小细节，可能经常忽视就会影响整个状态。比如：看剧久了没去学习会浪费一天的时间，经常忘记喝水对身体也不好。所以时时提醒很有必要～

NO.3

印象笔记

接下来我每天的工作安排，我倾向用印象笔记。原因是上班的时候用电脑，可以把他缩成一个小便利贴放在桌面。

我一般是到了公司就立马写下今天要做的事情，然后后面写上大概几个小时去完成。

如果完成工作有额外时间还可以去练习练习剪辑、看看抖音热点提升自己的专业技能。这样就是一个良性循环。

最后，还有几个不错的时间管理软件，大家可以参考：

// 1. 小日常⏰

和日历的功能有点重复，就是提醒你要做的事情。比如喝水、早起、给父母打电话这些事情，如果不能时时记在心上，就用这个提醒自己吧。

设计的也更好看。日历是苹果自带的，安卓可以试试这个。

// 2. 高效TODO📅

最近发现的一款好用的时间管理工具。

上面我所有提到的软件都不能替代这个，原因是：时间管理除了写下要做什么，分清轻重缓急也很重要。

这个app就把重要、紧急四个象限区分开，先做什么后做什么一目了然。尤其是最近一团糟的时候，更适合使用。

// 3. 专注面条🍜

声明：这是一个付费软件。

感觉大家对付费软件充满恶意哈哈～这个是一个类似 专注森林 的软件，专注森林是专注可以种树，这个是可以做出一碗面条。

我付费的原因是那天没有吃晚饭花6块钱买了个这个，好好享受工作学习，专注之后就收获一碗面的感觉非常不错。

最后，我想再声明一点：时间管理必须具有个性化和目的，才能真正管理好你的时间。

也就是说，无论上面提到多少工具，最终日程管理还是要根据自身情况。

比如我朝九晚六上班，晚8-10点做自己喜欢的事（写公众号拍抖音），日程管理的目的就是：平衡工作和爱好，让每周的生活都有趣一点。

所以我的时间管理目的：

（1）工作规划-每天上班全身心投入

（2）副业规划-抖音公众号正常更新不能停

（3）心情规划-健康生活不耽误

我的时间管理方式是：

手帐本：安排我的副业和记录每天心情

日历：安排我的生活，提醒日常

印象笔记：管理我的工作

这样抖音公众号我知道发什么内容，生活也知道按时喝水健身、工作也能高效安排。

但是如果你的生活是上班、想学习一个技能，可能一个hoboweeks就能解决；如果你是上学，每天上课还想过好生活，那一个国誉自我也能搞定。

总之，所有的工具都是为了时间管理，希望我们8月都能效率高高！
